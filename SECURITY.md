# Security and Privacy

Do not report a vulnerability by posting student information, credentials, private district files, or exploit details in a public issue.

Contact the repository owner privately through the GitHub account that owns this repository. Include the affected route, a concise reproduction, expected impact, and a safe proof of concept that contains no real student data.

The production site is static and stores progress in the current browser. The educator dashboard contains fictional sample data and is not connected to a live district system.
