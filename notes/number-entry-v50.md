# Automatic typed answers across the arcade

All ten active adventures now use a shared numeric-answer component: Horse Race, Wave Rider, Subway, Dirt Track, Star Defender, Dragon Quest, Ping-Pong, Seed, Castle and Neon Auto Shop. Four-choice controls are replaced by one answer field plus a twelve-key number pad (0–9, Clear, Backspace). Hardware keyboards work without a Submit button or Enter. Mobile input uses the in-game keypad so the operating system keyboard does not cover gameplay.

The expected integer answer's digit count defines completion. A one-digit entry is checked immediately. Two- and three-digit answers wait for all expected digits, even if an early digit is wrong. Zero is valid. Completed entries lock before the game callback, preventing duplicate rewards. Invalid/non-numeric or overlong pasted strings are rejected; a completed wrong entry earns nothing. Partial entries can be erased and remain intact through pause. Hidden pages and inactive game states reject input. Holding a key cannot auto-fill via key-repeat.

Problems are right-aligned vertically with the operation on the lower row and a rule above the answer field. For the three building games, the vertical problem stays on the center flashcard and the keypad stays beneath the three piles. Their uncover/settle sequence, review queue, reveal timing and video progress are preserved. The other games render the vertical problem and input together in the action console.

Existing rewards, shared fact mastery, upgrades, video behavior and 2/3/4/5-minute round options remain intact. Demos still autoplay and display typed numeric answers without saving rewards. Ping-Pong's wrong serve now always replaces the question, including standalone mode, instead of waiting for another try on the same fact. Flight-return misses still complete their ball animation. Dirt/Wave's three-second starting countdown now uses elapsed wall time rather than capped animation-frame time.

The separate common 90-second fluency assessment is not a game and remains unchanged. No wallet/progress reset or schema migration is needed. Cache tags updated for every active game entry and modified script, including Subway's dynamic game import and Horse's keyboard adapter.

Tests: pure digit-buffer and real component DOM tests, ten-page script/inline syntax and integration checks, shared pathways, timed rounds, reward/demos, Dragon encounter/visual regressions. Engine-runtime fixtures use a widget double; actual page input is checked separately using typing-qa.html at phone width. Native GPU graphics are unchanged and are not verified by the cloud browser's compatibility rendering.
Browser QA: all ten actual phone-width game pages passed complete correct and wrong entries, multi-digit partial retention when sampled, input locking and next-question advancement. Nine passed the full run; Subway passed an isolated retest after the QA runner was corrected to wait for its dynamically imported script's start handler. Initial cloud frame throttling also exposed the race countdown's capped-delta delay, now corrected. Manual hardware-keyboard testing in Ping-Pong confirmed partial `1` stays on 9 + 6, then final `5` launches the serve automatically. No actual user account or practice profile was modified during QA.
Final edge-case fix: each newly presented flashcard explicitly resets its numeric buffer even when a one-card review queue recycles the same card object. A DOM regression covers wrong answer, same-object retry, then correct answer. Demo wrong answers now stay within the expected digit width; shorter values display leading zeros so a demo never appears to submit an unfinished answer.
